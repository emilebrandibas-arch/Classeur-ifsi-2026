## Publication et mise à jour

- La version partagée repose sur `index.html`, `modules.js`, `planning.html` et les PDF du dossier `documents/`.
- GitHub Pages publie automatiquement chaque changement de la branche `main` avec `.github/workflows/pages.yml`.
- Le dossier de référence Google Drive « Classeur IFSI 2026–2029 — fiches Moodle A4-A5 » est comparé au dépôt par une tâche ChatGPT programmée. Cette tâche est **distincte** de GitHub Actions. La comparaison n'est pas une synchronisation instantanée ; elle dépend de l'exécution et des autorisations des connecteurs.
- Les boutons « Ajouter », « Modifier », « Archiver » du site stockent des changements **locaux au navigateur**. Ils ne publient pas ces changements sur GitHub ni chez les autres lecteurs. Pour modifier le classeur partagé, publier le PDF dans ce dépôt et mettre à jour la liste des documents dans `index.html`.
- Éviter les doublons : les PDF Drive sont stockés sous `documents/<id-fichier-drive>.pdf` ; ne pas ajouter de retranscriptions brutes.
- Une fois la publication terminée, les personnes ayant conservé le lien peuvent charger la nouvelle version. En cas de cache du navigateur, recharger la page.
